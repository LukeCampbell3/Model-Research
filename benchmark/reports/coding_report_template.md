# PVR-EC-O Coding Report Template

This is coding benchmark evidence only, not custom repository-workflow evidence.

Required sections:

- Function-level coding: HumanEval+, MBPP+, BigCodeBench Complete, BigCodeBench Instruct
- Contamination-resistant coding: LiveCodeBench or post-training-date internal tasks
- Multilingual code: MultiPL-E when applicable
- Repository context: RepoBench-R, RepoBench-C, RepoBench-P, local repo-context eval

Track pass rates, compile rates, runtime failures, timeouts, invalid syntax, context selection, patch locality, tokens, cost, and GPU-hour efficiency.
